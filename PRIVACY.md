# Privacy — Erthi | إرثي
This alpha stores preferences and learning progress on the device. It has no Internet, microphone, location or storage permission, analytics, advertising or remote accounts. Android backup is disabled. Language selection uses Android/AppCompat app locales. Clearing app storage or uninstalling removes local data. No cloud recovery is provided. Public contact: admin@erthi.org.

The operator is an individual using the public Erthi identity; Erthi-Org is not claimed to be a separate legal entity. Do not place private legal records, personal details or signing keys in this project.
